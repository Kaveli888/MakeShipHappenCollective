Fix the bug currently visible in the Vibe Academy API.

Process:
  1. Reproduce it. Paste the exact error/stack trace.
  2. Trace to root cause (not just symptom).
  3. Fix the root cause.
  4. Add a regression test.
  5. Confirm the test fails before the fix and passes after.

Done = root cause identified + fix + regression test passing + before/after error output.
