Working dir: vibe-academy-website (or whichever holds the public marketing site)

Goal: build out the marketing site with more sections, real stock photography, and zero generic AI-design feel.

Phase 1 — Audit (5 agents in parallel):
  Agent 1 (Current State): Screenshot every existing page. List every section. Rate each section 1-10 on distinctiveness and call out anything that screams "AI template."
  Agent 2 (Content Gaps): Identify missing sections that high-converting course/edtech sites have — testimonials, instructor bios, curriculum preview, outcomes/stats, FAQ, comparison vs. alternatives, pricing transparency, community proof, press/logos, newsletter capture.
  Agent 3 (Reference Set): Pull 5-7 best-in-class reference sites (NOT generic SaaS — think Maven, Lenny's Newsletter, ZTM, Frontend Masters, Build Your Own X-style sites). For each: what makes them work, what to steal, what to leave.
  Agent 4 (Stock Photo Sourcing Strategy): Identify the right stock photo sources (Unsplash, Pexels, specific photographers) and define the shot list — what kinds of images we need (real people coding, diverse builders, workspaces, screens) and which to AVOID (handshake-over-laptop cliches, fake-smile stock).
  Agent 5 (Content Voice): Audit current copy. Define a voice guide — tone, sentence length, words to use, words to ban. The marketing should sound like a builder talking, not a brochure.

Phase 2 — Plan:
  Output a structured build plan:
    - New sections in priority order
    - For each: purpose, copy direction, layout sketch, image needs, components required
    - Asset list (stock images + sources)
    - Voice guide (1 page)

Pause. Show me the plan and the moodboard of reference sites + chosen stock images BEFORE building.

Phase 3 — Build (use front-end design plugin, 5 agents in parallel):
  Each agent owns 1-2 sections. Per section:
    - Implement using the front-end design plugin
    - Source actual stock images (real photos, not illustrations, not AI generations)
    - Match the voice guide
    - Commit per section
    - Include before/after screenshots

Hard rules:
  - NO AI-generated images anywhere on the marketing site. Real stock only.
  - NO generic SaaS gradient hero. NO floating laptop mockup with code on it (overused).
  - NO "Empowering builders to..." or "Unlock your potential" copy. Ban list those phrases.
  - Stock images: prefer real candid shots over staged corporate photography.
  - Every section earns its place. If a section doesn't have a clear purpose, cut it.

Done per phase: audit delivered → plan + moodboard approved → sections shipped per commit → final walkthrough screenshots.
