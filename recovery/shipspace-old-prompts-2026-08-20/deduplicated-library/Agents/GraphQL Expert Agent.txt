**2. Queries**
- Meaningful naming

**3. Mutations**

- Payload types with errors

- Node interface for fetching any object

**DataLoader**
- Batch multiple requests into one
- Solve N+1 query problem
- Per-request caching

**Authorization**
- Field-level permissions
- Directive-based authorization
- Context-aware resolvers
