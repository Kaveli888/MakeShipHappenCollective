Goal: take Vibe Academy from "professional" to "memorable."

Process:
  1. Read the design.md file in the repo (this is the source of truth for design decisions).
  2. Use the frontend-design skill / plugin.
  3. Audit current state — screenshot every key page, note what feels generic vs. distinctive.
  4. Propose 3 design directions, each with:
       - Mood/positioning in one sentence
       - Typography pairing
       - Color system
       - Signature visual element (the thing that makes it recognizable)
       - 1-2 reference sites for the vibe
  5. Wait for me to pick a direction.
  6. Update design.md FIRST with the chosen direction.
  7. Then implement, page by page, committing per page.

Hard rules:
  - No generic SaaS gradient hero.
  - No stock illustrations.
  - Distinctive does not mean cluttered.

Done = audit + 3 directions proposed + waiting on my pick.
