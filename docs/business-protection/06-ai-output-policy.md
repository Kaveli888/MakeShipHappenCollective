# AI Output and Generated Code Responsibility Policy

Status: Public-facing draft for attorney review.

MakeShipHappen products use local models, user-configured providers, and/or hosted AI providers to assist with writing, coding, summarizing, transcribing, organizing, searching, reviewing, and automating work.

## AI Output Is Not Guaranteed

AI output may be inaccurate, incomplete, outdated, unsafe, biased, noncompliant, insecure, or inappropriate for a user's use case. Citations, summaries, analyses, code changes, agent verdicts, and generated artifacts are assistance, not guarantees.

## Human Review Required

Users are responsible for reviewing and verifying all AI outputs before:

1. Publishing or sharing them.
2. Using them in production.
3. Applying code changes.
4. Making business, legal, financial, healthcare, employment, safety, or compliance decisions.
5. Sending outputs to customers, clients, employees, students, patients, regulators, courts, or investors.

## Generated Code

Generated code may include bugs, insecure logic, licensing issues, breaking changes, dependency risks, or behavior that does not match the user's intent. Users are responsible for:

1. Reviewing diffs and generated files.
2. Running tests and security checks.
3. Confirming license compatibility.
4. Reviewing secrets and sensitive data exposure.
5. Maintaining, deploying, and supporting code in their own environment.
6. Ensuring code complies with applicable laws, contracts, and policies.

## Agent Actions

Agents may read, write, summarize, review, or suggest changes based on user instructions and product configuration. Users are responsible for the scope they provide, the automation modes they enable, and the final decision to apply, merge, publish, or rely on results.

## No Professional Advice

MakeShipHappen does not provide legal, medical, financial, tax, investment, employment, compliance, security-certification, or other professional advice. Users should consult qualified professionals before relying on outputs in regulated or high-impact contexts.

## Provider-Specific Terms

When users connect third-party AI providers or local models, those providers' terms, privacy policies, retention practices, and usage costs apply. Users are responsible for their provider accounts and API keys unless MakeShipHappen expressly provides hosted access under a separate plan.
