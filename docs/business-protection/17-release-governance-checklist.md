# Release Governance Checklist

Status: Internal non-code governance control.

Use before public release, pricing change, product-page update, new provider integration, new capture feature, new AI agent capability, or new paid plan.

## Product Status

- [ ] Product status is accurate: Live, Beta, Preview, Internal, Planned, or Experimental.
- [ ] Platform availability is accurate.
- [ ] Download/install claims are accurate.
- [ ] Coming-soon features are labeled.

## Legal

- [ ] Terms cover this product/feature.
- [ ] Privacy Policy covers this product/feature.
- [ ] Acceptable Use Policy covers expected misuse.
- [ ] Refund/cancellation terms remain accurate.
- [ ] No new professional-advice or regulated-use claim introduced.

## Privacy

- [ ] Privacy matrix updated.
- [ ] Data processing inventory updated.
- [ ] Subprocessor register updated.
- [ ] Retention schedule updated.
- [ ] Deletion/export SOP impact reviewed.
- [ ] Capture/recording consent responsibility reviewed.

## Claims

- [ ] Claims register updated.
- [ ] Absolute claims removed or substantiated.
- [ ] Performance claims have evidence.
- [ ] Security claims have evidence.
- [ ] Local/cloud mode claims are conditional and accurate.
- [ ] Comparative claims are substantiated.

## Operations

- [ ] Support docs updated.
- [ ] Incident response impact reviewed.
- [ ] Vendor risk register updated.
- [ ] Insurance implications reviewed.
- [ ] Community/support promises reviewed.

## Open Source / Distribution

- [ ] Dependency/license changes reviewed.
- [ ] Bundled binaries/models reviewed.
- [ ] Attribution/NOTICE obligations reviewed.
- [ ] Signing/update/release ownership documented.
