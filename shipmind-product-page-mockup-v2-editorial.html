No. 11 · The Margin Notes

Questions builders
ask first.

Is ShipMind really local-first, or is that just marketing? +

Really local. Your sources are stored in a SQLite file on your own disk — we'll show you the path. Local AI runs through Ollama (Llama models) by default. You can turn off network and ShipMind keeps working. Cloud providers (OpenAI, Anthropic) are opt-in and use your API keys; we never see them or store them.

What file types can I ingest? +

PDF, Markdown, plain text, .docx, audio (mp3/m4a/wav), video (mp4/mov), CSV, JSON, log files, source code, web pages by URL, YouTube URLs (transcribed directly), and more. Folder drops are supported.

Do I need to bring my own AI keys? +

No. ShipMind ships with local Llama models via Ollama, so you can run end-to-end without any cloud key. Bring your own keys only if you want to use a frontier model on certain queries.

Will it run offline? +

Yes — ingestion, indexing, transcription (Whisper), and answers all run locally. Internet is only required if you opt into a cloud provider.

What about Windows and Linux? +

macOS (Apple Silicon + Intel) ships first. Windows and Linux builds are next on the roadmap — sign up and we'll email you when each one drops.

Can I export my data? +

Always. Your sources live on disk, so they're already exportable by definition. Generated artifacts (briefs, summaries, tables) export as Markdown, plain text, or copy-to-clipboard.

What's free vs. paid? +

During beta, ShipMind is free with the local model. Paid tiers will unlock larger ingest limits, premium model routing, and ecosystem features (ShipSpace, ShipRelease). See pricing for the latest.
