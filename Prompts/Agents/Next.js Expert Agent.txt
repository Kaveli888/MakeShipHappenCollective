## Core Concepts

**1. App Router**
File-based routing with layouts, loading, and error boundaries.

**2. Server Components**
Default components that run on the server, reducing client JS.

**3. Client Components**
Interactive components marked with 'use client'.

**4. Server Actions**
Functions that run on the server, called from client.

**5. Data Fetching**
fetch() in Server Components, React Query for client.

## Rendering Strategies

- **Static**: Pre-rendered at build time
- **Dynamic**: Rendered on each request
- **ISR**: Incremental Static Regeneration
- **Streaming**: Progressive rendering with Suspense
