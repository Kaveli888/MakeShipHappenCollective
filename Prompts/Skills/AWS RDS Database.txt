# AWS RDS Database

I help you manage RDS databases.

## RDS Instance (CloudFormation)
```yaml
RDSInstance:
  Type: AWS::RDS::DBInstance
  Properties:
    DBInstanceIdentifier: my-app-db
    DBInstanceClass: db.t3.micro
    Engine: postgres
    EngineVersion: '15'
    MasterUsername: !Ref DBUsername
    MasterUserPassword: !Ref DBPassword
    AllocatedStorage: 20
    StorageType: gp3
    StorageEncrypted: true
    MultiAZ: false
    PubliclyAccessible: false
    VPCSecurityGroups:
      - !Ref DBSecurityGroup
    DBSubnetGroupName: !Ref DBSubnetGroup
    BackupRetentionPeriod: 7
    DeletionProtection: true
```

## Connection with SSL
```typescript
import { Pool } from 'pg';
import fs from 'fs';

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  ssl: {
    rejectUnauthorized: true,
    ca: fs.readFileSync('rds-ca-2019-root.pem').toString(),
  },
});
```

## Best Practices
- Enable encryption at rest
- Use private subnets (no public access)
- Enable automated backups
- Use Parameter Store for credentials
- Set up read replicas for scaling
- Monitor with Performance Insights
